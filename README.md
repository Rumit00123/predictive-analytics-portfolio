## Projects

### 01. Customer Loan Acceptance Prediction
**Tools:** R, caret, Machine Learning

Developed and compared five supervised learning models to predict customer acceptance of personal loan offers using the Universal Bank dataset.

**Techniques:**
- k-Nearest Neighbors (kNN)
- Naive Bayes
- C5.0 Decision Trees
- Artificial Neural Networks
- Support Vector Machines

**Methodology:** Stratified 80/20 train-test split, cross-validation, hyperparameter tuning, and classification performance evaluation.
